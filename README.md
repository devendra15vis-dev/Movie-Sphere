# 🎬 Movie Hub

Movie Hub is a modern and responsive movie discovery website designed to help users search, discover, and explore movies through a clean and cinematic interface.

## 🌟 Overview

Movie Hub provides an easy way to explore movies, search the movie archive, and view information about different movies.

The project focuses on creating a smooth user experience with a dark cinematic UI and dynamic movie content.

## ✨ Features

- 🔍 Search movies by title
- 🎬 Browse popular movies
- ⭐ Display movie ratings
- 📅 Display movie release year
- 🎞️ Movie posters and visual cards
- 📖 Movie details page
- 🏠 Modern landing/home page
- ℹ️ About page
- 📱 Responsive design
- ⚡ Dynamic movie data
- 🎨 Cinematic dark-theme interface

## 📸 Main Sections

### 🏠 Home Page

The landing page introduces Movie Hub with:

- Movie search bar
- Featured search section
- Movie discovery options
- Popular movie section
- Navigation menu

### 🔎 Movie Search

Users can search the movie archive by entering a movie title.

The search results are displayed dynamically with movie posters and basic information.

### 🔥 Popular Movies

The website includes a section for popular movies where users can discover movies such as:

- The Avengers
- Avengers: Endgame
- Avengers: Infinity War
- Avengers: Age of Ultron

### 🎥 Movie Details

Users can select a movie and navigate to a dedicated movie details page to explore more information about it.

### ℹ️ About Page

The About page provides information about the Movie Hub project.
